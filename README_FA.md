# راهنمای نسخهٔ ۳.۵ DAYRIXA

فایل را از حالت فشرده خارج کن و در پوشهٔ آن `python -m http.server 8080` را اجرا کن. آدرس `http://localhost:8080/ai/` را باز کن و به Data Analyst برو.

چهار بخش اصلی:

| بخش | کار اصلی |
|---|---|
| Start | انتخاب هدف |
| Data | آماده‌سازی، ساخت متغیر، ادغام و اجرای مجدد |
| Analysis | برازش مدل، CAPM، مقایسه و بررسی حساسیت |
| Results | گزارش، داده، پروژه و LaTeX |

ابزارهای قدیمی داخل Explore data & additional tools باقی مانده‌اند. تنظیمات تخصصی مدل بازشدنی هستند. متن محیط جدید فعلاً انگلیسی است.

## دو قابلیت اصلی جدید

**اثر تصمیم:** یک مدل را ذخیره کن و What changes if…? را باز کن. حذف داده‌های پرت، تغییر بازهٔ زمانی یا تغییر متغیرهای توضیحی را بررسی کن. تعداد مشاهدات و تفاوت ضرایب نمایش داده می‌شود؛ دادهٔ اصلی تغییر نمی‌کند. برای تغییر متغیرها، هر دو مدل روی نمونهٔ مشترک برآورد می‌شوند. افزایش R² به‌معنی بهتر بودن علمی مدل نیست.

**اجرای مجدد:** آماده‌سازی را در بخش جدید Data انجام بده، متغیر و ادغام را بساز و مدل را ذخیره کن. Repeat with new files اجازه می‌دهد دستور مراحل را در JSON ذخیره کنی و روی فایل‌های جدید اجرا کنی. هر فایل دوم ادغام باید مجدداً انتخاب شود. ابتدا پیش‌نمایش می‌بینی؛ بعد از تأیید، اجرای جدید جای اجرای فعلی را می‌گیرد. برای نگهداری نسخهٔ قبلی، قبل از اعمال، پروژه را ذخیره کن.

مراحل قدیمی که فقط به صورت متن در تاریخچه ثبت شده‌اند، قابل بازسازی خودکار نیستند. عملیاتی مثل حذف یک ردیف با شماره، در اجرای مجدد مسدود می‌شوند. این کار مانع اعمال یک دستور نامناسب روی ردیف متفاوت در فایل بعدی می‌شود. از کنترل‌های آماده‌سازی جدید برای ساخت دستور قابل تکرار استفاده کن.

## CAPM و ادغام

در CAPM باید مشخص کنی Rf بازده همان دوره است یا نرخ سالانه. اگر تعریفش نامعلوم یا سالانه است، ابتدا باید مبنای صحیح تبدیل را تعیین و ستون مناسب را بسازی؛ برنامه خودکار بر ۱۲ تقسیم نمی‌کند. واحد Ri، Rm و Rf باید یکسان باشد.

در ادغام، یکتایی کلید سمت دوم کنترل می‌شود. برای دو پنل معمولاً شناسه و تاریخ لازم است. در صورت وجود یک پیشنهاد مناسبِ کلید مرکب، کنار پیام مشکل راه دسترسی به آن نمایش داده می‌شود. معنی واقعی شناسه‌ها همچنان باید توسط کاربر تأیید شود.

## خروجی پژوهشی

در Results گزینهٔ Download LaTeX (.tex) اضافه شده است. فایل را با XeLaTeX یا LuaLaTeX کامپایل کن. ضرایب، SE، t، مشخصات مدل، نمونه، ضرایب ثابت و نتایج مقایسه/حساسیت درج می‌شوند. نمونهٔ واقعیِ بررسی‌شده در پوشهٔ examples است. این خروجی قالب یک ژورنال خاص نیست و برای متن فارسی ممکن است تنظیم فونت و راست‌به‌چپ لازم باشد.

## چه چیزهایی بررسی شده‌اند؟

- نتیجهٔ فایل واقعی ۲۰۷‌مشاهده‌ای و تمام مقادیر عددی واردشده با استخراج مستقل کنترل شدند.
- آزمون‌های OLS/HC1 و ضرایب ثابت، نمونه‌های حساسیت، کنترل ادغام و اجرای مجدد گذشتند.
- در آزمون اجرای مجدد، افزایش ۵ واحدی متغیر وابسته، عرض از مبدأ جدید را دقیقاً ۵ واحد افزایش داد؛ نتیجهٔ قبلی استفاده نشد.
- نمونهٔ LaTeX واقعاً کامپایل و جدول آن بررسی شد.

رابط در DOM شبیه‌سازی‌شده آزمایش شده است؛ ظاهر و کارکرد مرورگر واقعی، موبایل، سرعت شبکه و کارایی روی پنل‌های بسیار بزرگ تأیید نشده‌اند. هیچ پایلوت واقعی با پنج کاربر هنوز انجام نشده است. راهنمای اجرای آن در PILOT_GUIDE_FA.md قرار دارد.
